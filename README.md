# Обнаружение фейковых новостей: Модель классического машинного обучения

Это проект по созданию модели машинного обучения для автоматического определения **фейковых новостей**. 📰 Модель успешно достигла высокой точности, превышающей 90%, что доказывает её эффективность в решении этой актуальной проблемы. 

---

### **Технические детали**

* **Язык программирования:** Python
* **Библиотеки:**
    * **Scikit-learn:** Основная библиотека для построения модели.
    * **TfidfVectorizer:** Используется для преобразования текстовых данных в числовые векторы.
    * **Passive Aggressive Classifier:** Выбран для обучения модели благодаря своей эффективности на потоковых данных.
    * **Pandas и NumPy:** Необходимы для обработки и анализа данных.
    * **Matplotlib, Seaborn и Plotly:** Применяются для визуализации результатов.

---

### **Методология**

1.  **Извлечение признаков:** Текстовые данные преобразуются в числовые векторы с помощью **TfidfVectorizer** для дальнейшего анализа.
2.  **Обучение модели:** Используется **Passive Aggressive Classifier** для обучения модели на подготовленных данных.
3.  **Оценка результатов:** Производится оценка модели с помощью метрик **accuracy_score** и **confusion_matrix**, что позволяет убедиться в её надёжности.

---

### **Результаты**

* **Точность:** Модель показала впечатляющую точность в **92.82%**.
* **Визуализация:** Результаты включают визуализацию **матрицы ошибок (confusion matrix)** и **отчёта о классификации**, что помогает наглядно оценить производительность модели. 
* **Надёжность:** Модель успешно классифицирует новые, невидимые данные, что подтверждает её способность к обобщению.
